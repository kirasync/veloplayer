# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-15
### Added
- Initial release of VeloPlayer Web Component
- Basic playback controls (Play, Pause, Mute, Volume, Fullscreen, PiP, Seek)
- Support for customizable `accent-color` and `aspect-ratio`
- Framework-agnostic design
- Responsive layout
- Standalone `/player.js` script generation
