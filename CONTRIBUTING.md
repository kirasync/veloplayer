# Contributing to VeloPlayer

First off, thank you for considering contributing to VeloPlayer!

## Development Setup

1. Clone the repository.
2. Install dependencies: \`npm install\`
3. Start the dev server: \`npm run dev\`

## Testing

Tests are written using Vitest (Unit) and Playwright (E2E).

- Run unit tests: \`npm run test\`
- Run E2E tests: \`npm run test:e2e\`
- Run coverage: \`npm run test:coverage\`

All tests must pass before submitting a Pull Request.

## Pull Request Process

1. Ensure any install or build dependencies are removed before the end of the layer when doing a build.
2. Update the README.md with details of changes to the interface, if any.
3. Your code must follow the existing style and pass tests.
